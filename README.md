Платіжна інструкція в іноземній валюті — це документ, який використовується для переказу коштів за кордон або на валютні рахунки всередині України. Основні правила оформлення регламентуються інструкціями Національного банку України (НБУ).Обов'язкові реквізити та покрокова інструкція для успішного проведення платежу включають наступні кроки:1. Обов'язкові реквізити платежуПравильність заповнення — запорука того, що платіж не буде відхилений банком-кореспондентом. Інструкція повинна містити:Код платника: Ваші реквізити як відправника (код ЄДРПОУ для юридичних осіб або реєстраційний номер облікової картки платника податків для ФОП/фізичних осіб).Дані отримувача: Повне найменування компанії або ПІБ особи.IBAN рахунок отримувача: Номер рахунку, а для міжнародних переказів — міжнародний формат банківського рахунку.SWIFT-код: Банківський ідентифікаційний код банку отримувача.Код валюти: Цифровий або літерний код згідно з Класифікатором іноземних валют НБУ (наприклад, USD або 840).Сума платежу: Цифрами та прописом (копійки/центи відокремлюються комою).Призначення платежу: Чіткий опис суті операції, наприклад: оплата за договором, інвойс, рахунок-фактура.2. Розподіл комісії (Charges)В інструкції обов'язково вказується, хто сплачує комісію банків-посередників (Intermediary):OUR: Усі комісії (і банку відправника, і банків-кореспондентів) сплачує платник. Отримувач отримає точну суму.BEN: Усі комісії сплачує отримувач (сума комісії вираховується з переказу).SHA: Комісію банку відправника оплачує платник, а комісію за послуги банків-кореспондентів — отримувач.3. Додаткові вимоги (Валютний контроль)Для переказів, що перевищують встановлені НБУ ліміти (або згідно з внутрішнім комплаєнсом банку), необхідно надати підтвердні документи. Це можуть бути: ЗЕД-договір, інвойс, акти виконаних робіт, митні декларації.Якщо валюта купується під операцію, додатково подається Заява про купівлю іноземної валюти.Документи подаються через систему дистанційного банківського обслуговування (наприклад, Клієнт-Банк, iFOBS, або онлайн-кабінет для бізнесу), використовуючи електронний підпис (КЕП).
